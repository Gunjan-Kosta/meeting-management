================================================================================
          ENTERPRISE MEETING MANAGEMENT & COMPLIANCE SYSTEM
                          SYSTEM FEATURES & SPECIFICATION
================================================================================

1. SYSTEM OVERVIEW
--------------------------------------------------------------------------------
The Enterprise Meeting Management System is a governance portal built to track,
manage, and monitor high-level government meetings, compliance action items,
departmental responsibilities, and official documentation across state and district levels.


2. ROLE-BASED ACCESS CONTROL (RBAC)
--------------------------------------------------------------------------------
The system supports 3 distinct user roles with strict permission boundaries:

  A. State Administrator (STATE_ADMIN)
     - Full administrative access across all districts and departments.
     - Capability to create, edit, submit, close, and delete meeting records.
     - Manage department registers and user accounts.
     - View complete system Audit Logs and analytics.

  B. District Officer (DISTRICT_USER)
     - Scoped to their assigned district (e.g., Bhopal, Indore).
     - Can create draft meetings and update draft meeting details.
     - Can upload documents, add participants, and track action items.
     - Cannot edit or delete meetings once submitted or closed.

  C. Public Auditor / Viewer (VIEWER)
     - Read-only access across meetings, action items, and reports.
     - Cannot create, edit, submit, or delete meeting records or documents.


3. THEME & USER INTERFACE
--------------------------------------------------------------------------------
  - Permanent Dark Theme Interface: Designed with dark slate tones, vibrant badges,
    and high contrast typography.
  - Fully Responsive Layout: Mobile drawer navigation and adaptive data tables for
    desktops, tablets, and smartphones.


4. EXECUTIVE DASHBOARD
--------------------------------------------------------------------------------
  - Metric Summary Cards:
    * Total Meetings
    * Pending Meetings
    * Completed Meetings
    * Pending Action Items
    * Completed Action Items
    * Total Departments
  - Interactive Analytics Charts:
    * Monthly Meetings Volume (Bar Chart)
    * Meeting Type Distribution (Pie Chart)
  - Quick action shortcuts for authorized roles.


5. MEETING MANAGEMENT & LIFECYCLE
--------------------------------------------------------------------------------
  - Meeting Status Flow: [ DRAFT ] ---> [ SUBMITTED ] ---> [ CLOSED ]
  - Auto-generated Meeting Codes (e.g., MEET-2026-0001).
  - Categorization into official meeting types:
    * District Level Meeting
    * Sansad Meeting
    * Rajya Sadak Suraksha Parishad
    * Samiksha Baithak
    * Mantri Parishad Meeting
  - Mandatory MoM Requirement: A meeting status CANNOT be transitioned to SUBMITTED
    unless a Minutes of Meeting (MoM) document has been uploaded.


6. DOCUMENT MANAGEMENT & CATEGORIZED SECTIONS
--------------------------------------------------------------------------------
  - Categorized Document Upload Sections:
    1. MoM (Minutes of Meeting) - Mandatory for meeting submission
    2. Attendance Sheet - Optional
    3. Agenda Document
    4. Proceedings Document
    5. Supporting Documents
  - File Validation: Supports PDF, DOCX, and XLSX formats up to 10MB per file.
  - Total Document Quota: Maximum limit of 10 documents per meeting in total,
    enforced on both client-side UI and backend API.


7. SEARCH & ADVANCED FILTERING
--------------------------------------------------------------------------------
  - Global Search: Real-time search across meeting code, title, venue, and district.
  - Advanced Filter Controls:
    * Meeting Type filter dropdown
    * Status filter dropdown (Draft, Submitted, Closed)
    * District text filter
    * Meeting Date Range filter (From Date & To Date pickers)
    * Year filter
    * One-click "Reset Filters" action


8. COMPLIANCE & ACTION ITEM TRACKER
--------------------------------------------------------------------------------
  - Assign action items to specific government departments with target completion dates.
  - Track action item lifecycle: [ PENDING ] ---> [ IN_PROGRESS ] ---> [ COMPLETED ].
  - Record progress remarks and departmental compliance status.


9. DEPARTMENT & USER MANAGEMENT
--------------------------------------------------------------------------------
  - Department Registry: Manage state departments, code identifiers, and user allocations.
  - User Management: Create and update user accounts, roles, and district assignments.


10. AUDIT LOGGING & SECURITY
--------------------------------------------------------------------------------
  - Immutable Audit Logs tracking every system action (login, create meeting, submit,
    upload document, delete, update action item) with user details, timestamp, and IP address.
  - Secure JWT authentication with hashed passwords (bcrypt).
