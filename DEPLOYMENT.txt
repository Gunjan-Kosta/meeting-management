1. OVERVIEW & 100% FREE CLOUD PERSISTENCE
--------------------------------------------------------------------------------
The backend is now powered by Prisma ORM with native MongoDB Atlas support.
MongoDB Atlas provides a 100% free, forever-persistent cloud database cluster (M0)
that is completely independent of container redeployments.

Benefits:
  - Zero paid subscriptions or disks required on Render or Vercel.
  - 100% of your created meetings, uploaded document records, action items,
    modified passwords, and audit logs are permanently stored in the cloud.
  - Every time a new commit is pushed to GitHub, existing data in MongoDB
    Atlas remains 100% untouched.


2. HOW TO CONNECT MONGODB ATLAS ON RENDER
--------------------------------------------------------------------------------
Step 1: Get Your MongoDB Atlas Connection String
  1. Go to https://cloud.mongodb.com and log in.
  2. Click 'Connect' on your cluster -> 'Drivers' (Node.js).
  3. Copy your connection string:
     mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/meeting_management?retryWrites=true&w=majority
     (Replace <username> and <password> with your database user credentials).

Step 2: Add Environment Variables in Render
  1. Open your Render Web Service dashboard (meeting-management-backend).
  2. Go to the 'Environment' tab.
  3. Set / Update the following environment variables:
       - DATABASE_URL: mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/meeting_management?retryWrites=true&w=majority
       - JWT_SECRET: (e.g. gov_meeting_mgmt_prod_jwt_secret_983f21a47b0e56c1d42890ef)
       - JWT_EXPIRES_IN: 24h
       - NODE_ENV: production
       - FRONTEND_URL: https://meeting-management-client.vercel.app

Step 3: First-Time Setup on MongoDB
  When your Render backend boots for the first time with your MongoDB connection string,
  it will automatically initialize default departments, admin accounts, and indexes safely!
  Alternatively, you can run from the Render Shell tab:
     npm run db:setup
