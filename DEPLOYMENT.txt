1. DEPLOYMENT OVERVIEW
--------------------------------------------------------------------------------
This guide outlines production deployment for both components:
  - Backend API (/server): Deployed to Render / Railway / VPS / Docker
  - Frontend SPA (/client): Deployed to Vercel (or Netlify / Cloudflare Pages)


2. BACKEND CLOUD DEPLOYMENT ON RENDER (RECOMMENDED)
--------------------------------------------------------------------------------
Render provides automated Node.js Web Service hosting.

Step 1: Push Repository to GitHub
  Ensure your latest changes are pushed to:
  https://github.com/Gunjan-Kosta/meeting-management

Step 2: Create a New Web Service on Render
  1. Log into Render (https://render.com) and click 'New +' -> 'Web Service'.
  2. Connect your GitHub repository 'meeting-management'.
  3. Configure parameters:
       - Name: meeting-management-backend
       - Root Directory: server
       - Environment: Node
       - Build Command: npm install && npx prisma db push && node seed.js
       - Start Command: npm start

  4. Environment Variables:
       - JWT_SECRET: (Use a secure key, e.g. gov_meeting_mgmt_prod_jwt_secret_983f21a47b0e56c1d42890ef)
       - JWT_EXPIRES_IN: 24h
       - NODE_ENV: production
       - DATABASE_URL: file:./dev.db
       - FRONTEND_URL: https://your-app-name.vercel.app (Set your Vercel URL once created)

  5. Click 'Create Web Service'.
     Render will assign a live API domain (e.g. https://meeting-management-backend.onrender.com).


3. FRONTEND DEPLOYMENT ON VERCEL (STEP-BY-STEP)
--------------------------------------------------------------------------------
Vercel is optimized for React and Vite single-page applications.

Step 1: SPA Rewrites Configuration (Pre-configured)
  The file `client/vercel.json` is already included in your repository to prevent
  404 errors on page refresh:
  {
    "rewrites": [
      { "source": "/(.*)", "destination": "/index.html" }
    ]
  }

Step 2: Import Repository in Vercel
  1. Log into Vercel (https://vercel.com) and click 'Add New' -> 'Project'.
  2. Import your GitHub repository: Gunjan-Kosta/meeting-management.

Step 3: Configure Build & Directory Settings
  1. In the 'Project Settings' section:
       - Framework Preset: Vite
       - Root Directory: Click 'Edit' and select 'client'
       - Build Command: npm run build
       - Output Directory: dist
       - Install Command: npm install

Step 4: Environment Variables Setup
  1. Expand the 'Environment Variables' section on Vercel.
  2. Add the following key-value pair:
       - Key: VITE_API_BASE_URL
       - Value: https://meeting-management-backend.onrender.com/api
         (Replace with your actual live Render backend URL, appending /api)

Step 5: Deploy & Verify
  1. Click 'Deploy'.
  2. Vercel will build your React application and generate a live URL 
     (e.g. https://meeting-management-client.vercel.app).
  3. Open your live Vercel URL in your browser and sign in using the demo accounts.


4. OTHER BACKEND DEPLOYMENT OPTIONS
--------------------------------------------------------------------------------

OPTION A: RAILWAY.APP
  1. Create New Project on Railway -> Deploy from GitHub repo.
  2. Set Root Directory: /server
  3. Build Command: npm install && npx prisma db push && node seed.js
  4. Start Command: npm start
  5. Add Environment Variables: JWT_SECRET, NODE_ENV=production, PORT

OPTION B: LINUX VPS (AWS EC2 / DIGITALOCEAN)
  1. Connect via SSH: ssh ubuntu@your-server-ip
  2. Install Node v18+, PM2, and Nginx:
     curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
     sudo apt-get install -y nodejs git nginx && sudo npm install -g pm2
  3. Clone & Build:
     git clone https://github.com/Gunjan-Kosta/meeting-management.git
     cd meeting-management/server && npm install && npx prisma db push && node seed.js
  4. Start PM2: pm2 start app.js --name meeting-backend && pm2 save

OPTION C: DOCKER CONTAINER
  1. Dockerfile in /server:
     FROM node:18-alpine
     WORKDIR /app
     COPY package*.json ./
     RUN npm install
     COPY . .
     RUN npx prisma generate && npx prisma db push
     EXPOSE 5000
     CMD ["npm", "start"]
  2. Build & Run:
     docker build -t meeting-backend ./server
     docker run -d -p 5000:5000 --name meeting-api meeting-backend
